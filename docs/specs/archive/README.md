# RFC Archive

This directory contains archived RFCs that have been deprecated and moved from active status.

## Purpose

Per RFC-900 (RFC Deprecation List and Number Segment Reclassification Scheme), RFCs that are superseded remain in deprecated status for a minimum of 90 days before being archived here. This ensures:

1. **Historical preservation** - Archived RFCs retain their original content for reference
2. **Dependency tracking** - Links and references can still be resolved
3. **Clean active index** - The main `rfc-index.md` only shows active RFCs

## Lifecycle

```
Draft → Proposed → Accepted → Implemented → Deprecated → Archived
```

- **Deprecated**: Superseded by newer RFC, retained in `docs/specs/` for 90 days
- **Archived**: Moved to `docs/specs/archive/` after 90-day hold period
