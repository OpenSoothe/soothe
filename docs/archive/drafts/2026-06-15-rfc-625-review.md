## Completion Approaches

### Approach A: Full LLM Integration (Recommended)

Complete RFC-625 as specified with full LLM integration.

**Pros:**
- Delivers RFC-625 vision fully
- LLM-driven verification is core value proposition
- Consistent with RFC-200 backoff reasoning pattern

**Cons:**
- Higher implementation effort (~5 days remaining)
- LLM API cost for background verification cycles
- Need prompt engineering for structured output

**Effort:**
- LLM Reasoners: 2 days
- TUI GoalDAGCard: 2 days
- Config + integration: 1 day

### Approach B: Heuristic MVP + Deferred LLM

Mark RFC-625 Phase 1-3 as "complete", defer LLM integration to separate RFC-626.

**Pros:**
- Faster path to usable autopilot monitor
- Current heuristic placement works for basic cases
- Allows LLM integration refinement in dedicated RFC

**Cons:**
- Less intelligent DAG management
- Placement analysis is simplistic
- Dreaming distillation not functional

**Effort:**
- Config cleanup: 1 day
- TUI GoalDAGCard: 2 days
- RFC-626 proposal: 0.5 day

### Approach C: Minimal Completion

Complete only Config additions and mark RFC-625 as implemented with limitations noted.

**Pros:**
- Minimal effort
- Documentation reflects current state

**Cons:**
- RFC-625 claims LLM-driven verification not delivered
- User expectation mismatch

---

## Recommendation

**Approach A (Full LLM Integration)** is recommended:

1. The heuristics in current implementation are placeholders — LLM integration was the core RFC-625 design intent.
2. BackoffReasoner already has LLM integration pattern to follow.
3. The monitor skeleton is well-structured; adding reasoners is straightforward.
4. Completing RFC-625 fully avoids architectural drift.

**Proposed completion order:**

| Step | Scope | Days |
|------|-------|------|
| 1 | Config additions §13 | 0.5 |
| 2 | DagVerificationReasoner + prompts | 1 |
| 3 | DreamingDistillationReasoner + prompts | 1 |
| 4 | Wire reasoners into Verifier/Coordinator | 0.5 |
| 5 | TUI GoalDAGCard widget | 2 |
| 6 | Integration tests | 1 |

**Total: ~5 days**
